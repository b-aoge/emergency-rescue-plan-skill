## 二、关键场景判定与特殊处理

- **现场无宿舍** → 全文删除"宿舍"表述：危险源"临时建筑"由（办公室、宿舍、围挡）改为（办公室、临时休息区、围挡）；触电条款"现场宿舍用电"→"现场办公及休息区用电"；中暑预防"宿舍饭堂厨房"→"临时休息区及食堂厨房"、"工人回宿舍前洒水"→"工人进入临时休息区前洒水"；传染病管理"宿舍、办公室…"→"办公室、食堂、淋浴厕所、临时休息区…"。
- **无超危大工程** → 删除"专家论证"等字样；保留"深基坑/地下池体、钢结构吊装须编制专项施工方案并按方案实施"。
- **危化品/有限空间属性（异辛酸项目）** → 危险源补"可燃蒸气（VOC）积聚遇明火"；有限空间作业补"先通风、再检测、后作业"、防毒面具/供氧、系安全绳、专人监护；化学品接触皮肤/眼睛用大量清水冲洗≥15 分钟；附件4 增设"易燃易爆及有限空间作业预防措施"专节。
- **医院更名** → 原"张家港市沙洲医院"改为"张家港市乘航医院德积院区"（用户明确告知）。
- **附图** → 施工总平面布置图（PDF 转 PNG 嵌入附件5）、应急救援路线图（高德截图嵌入附件6）。
- **目录与编制依据分页** → 封面后 `---` 插入目录并 `add_page_break()`，使"一、编制依据"起新页。
- **页数控制** → 正文 10.5pt、行距 1.25、段后 3pt、表格 10pt、图片 14→11cm，最终 38 页（≤40）。

## 三、踩过的坑（已沉淀进 SKILL.md）

1. 在线预览（腾讯文档）不刷新 PAGEREF 域，目录页码全显示占位"2" → 必须用 Word COM 算真实页码并写死为静态文本。
2. 路线图是手机长截图（高宽比≈2.2），11cm 宽时高度超单页被挤到下一页 → 压到 8cm 并给"附件6"标题加 `page_break_before` + `keep_with_next`。
3. 用户要求"全文不要彩色字" → `set_cjk` 默认黑色，Normal/Heading 样式也显式设黑，删掉所有红色提示字。
4. Bash 沙箱在本机不稳定（临时目录丢失报错）→ 改用 PowerShell 执行 python，输出重定向到 .txt 再用 Read 读取。
