# 现场应急救援预案 编制 Skill

一个面向施工项目的 [WorkBuddy](https://www.workbuddy.cn) / CodeBuddy Skill：把零散的个性化信息，自动生成一份排版规范、可直接打印 / 报审的《施工现场应急救援预案》Word（docx）文档（约 35–40 页）。

> 适用场景：房建、市政、工业厂房、安装等**建设工程施工项目**的「应急救援预案」「事故应急预案」「现场应急处置方案」「应急抢险预案」等现场安全管理文档。
> 依据：《生产经营单位生产安全事故应急预案编制导则》**GB/T 29639-2020** 与施工行业惯例。

---

## 功能特点

- **标准结构一键对齐**：正文固定 9 章 + 附件 1–6，目录条目与正文标题严格一一对应。
- **附件正文库可复用**：附件 1–4（常见事故急救常识、火灾逃生自救、灭火器使用、各类事故预防措施）是高度可复用的行业通识文本，随 Skill 内置，按项目工艺属性微调即可。
- **python-docx 排版引擎**：
  - 全文字体黑色（标题黑体 / 正文宋体），符合国内施工资料报审规范；
  - 封面签名区居中留白、目录独立一页、页脚「第 N 页」自动页码；
  - 表格 100% 版心、固定列宽、表头蓝底、单元格垂直居中；
  - 标题 / 图片 `keep_with_next`，避免「标题在页尾、图在下一页」。
- **目录真实页码写死**：针对腾讯文档等在线预览**不刷新 Word 域（PAGEREF）**的坑，提供 Word COM 计算真实页码并写死为静态文本的工作流，所有阅读器都能正确显示。
- **可校验**：导出 PDF 逐页核对目录页码、全文字色校验、易漏项（宿舍 / 专家论证 / 占位）全文检索。

## 文档结构（9 章 + 附件）

| 章节 | 内容 |
|---|---|
| 一、编制依据 | 法律法规 + 标准规范清单（安全生产法、建筑法、GB/T 29639-2020、JGJ46/59/80、GB50497、GB50016 等） |
| 二、基本原则与方针 | 安全第一、预防为主、综合治理、自救为主、统一指挥、分工负责 |
| 三、工程项目基本情况 | 工程总体概述 + 现场医疗 / 消防救助设施 |
| 四、可能发生事故的确定及主要危险源 | 事故类型（坍塌、高处坠落、触电、火灾爆炸、中毒窒息等）+ 主要危险源 |
| 五、应急机构的组成、责任和分工 | 领导小组 + 应急联络一览表 + 指挥流程图 + 职责分工 |
| 六、报警信号与通讯 | 报警电话清单 + 报警注意事项 + 联络电话表 |
| 七、应急响应与救援 | 一般 / 重大事故响应、报告时限、现场救援措施表、演练评价 |
| 八、有关规定和要求 | 9 条岗位责任制与演练学习要求 |
| 九、附件 | 附件1–4 急救 / 逃生 / 灭火器 / 预防措施，附件5 施工总平面布置图，附件6 应急救援路线图 |

    ├── build_docx.py              # docx 排版引擎：plan_part1~5.md → 生成版 docx
    ├── compute_pages.py           # 用 Word COM 计算真实页码并写入 toc_pages.json
    └── verify_toc.py              # 导出 PDF 逐页核对目录页码与字色校验

## 使用工作流（5 步）

1. **收集个性化信息（先问再写）**：工程基本信息、项目人员（应急小组 + 电话）、就近医院、公司应急办电话；并判定关键场景（有无宿舍 / 超危大工程 / 危化品有限空间）、是否提供附图。缺失项须明确标注「占位 / 示例」。
2. **拆分源文件**：将内容拆为 `plan_part1.md`～`plan_part5.md`，按 SKILL.md 约定的封面 / 章节 / 表格 / 图片语法编写。附件 1–4 直接复制 `references/attachments_bank.md` 并按项目微调。
3. **构建 docx**：运行 `scripts/build_docx.py`，读取 `plan_part1~5.md`，输出 `施工现场应急救援预案_生成版.docx`。
4. **计算并写死真实页码（关键）**：先以 PAGEREF 模式构建一次 → 运行 `scripts/compute_pages.py` 用 Word 算真实页码写入 `toc_pages.json` → 再次运行 `build_docx.py`，目录页码写成静态文本。
5. **校验与交付**：用 `verify_toc.py` 核对目录页码，全文检索易漏项，交付时提醒封面签名与附图占位需替换。

> 完整语法约定、环境搭建、常见调整与坑点见 `SKILL.md`。

## 环境依赖

- Python 3 + 虚拟环境，安装：`python-docx`、`pywin32`、`PyMuPDF`（fitz）。
- `compute_pages.py` 依赖 **Windows + 已安装 Microsoft Word**（通过 `win32com` 调用 Word COM）。
- 中文字体直接使用「宋体 / 黑体」（Word 内部字体名），无需额外字体文件。
